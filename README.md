# HACKMAN

해커톤·공모전 운영 플랫폼

대회를 만들고, 팀을 꾸리고, 심사위원이 채점하면 순위가 실시간으로 갱신됩니다. 학과·동아리
규모의 행사를 설치 없이 브라우저에서 바로 운영할 수 있습니다.

**서비스 주소: https://hackman-sju.vercel.app/**

## 이런 걸 할 수 있습니다

| 역할 | 할 수 있는 일 |
|---|---|
| **운영자** | 대회 생성·삭제, 진행 단계 전환, 심사위원 배정, 발표 순서·시간 관리, 시상 진행 |
| **참가자** | 프로필 작성, 팀 추천받기, 팀 생성·참가, 제출물 등록·수정 |
| **심사위원** | 배정된 대회의 제출물에 예선/결선 점수와 코멘트 입력 |
| **관람자** | 로그인 없이 대회 목록과 실시간 스코어보드 열람 |

가입한 계정은 기본적으로 참가자입니다. 운영자가 배정하면 심사위원이 되고, 운영자 권한은
관리자가 부여합니다.

## 시작하기

**참가자라면** — 회원가입 → 대회 선택 → 프로필 작성 → 팀 만들기 또는 추천받은 팀에 참가

**운영자라면** — 로그인 → **+ 새 대회 만들기** → 심사위원 배정 → 대회 당일 단계 전환

**심사위원이라면** — 회원가입 후 운영자에게 아이디를 알려주면 배정됩니다

## 대회 진행 단계

```
모집중 ──▶ 진행중 ──▶ 심사중 ──▶ 종료
팀 구성      개발·제출    심사위원 채점   시상
```

단계마다 가능한 일이 정해져 있어, 심사 중에 제출물이 바뀌거나 종료된 대회에 점수가 들어가는
일이 없습니다.

| | 모집중 | 진행중 | 심사중 | 종료 |
|---|:-:|:-:|:-:|:-:|
| 팀 만들기 / 참가하기 | O | – | – | – |
| 제출물 등록 / 수정 | O | O | – | – |
| 심사위원 채점 | – | – | O | – |
| 스코어보드 보기 | O | O | O | O |

운영자는 **어느 단계로든 자유롭게 되돌릴 수 있습니다.** 실수로 단계를 넘겼거나 모집을 다시
열어야 할 때를 위한 것이며, 되돌려도 팀·제출물·점수는 그대로 남습니다.

허용되지 않는 단계에서 버튼을 누르면 `현재 상태: 심사중` 같은 안내가 뜨고 저장되지 않습니다.

## 주요 기능

### 스코어보드

대회 상세 화면 맨 위에 있습니다.

- **예선 / 결선** 탭으로 라운드를 나눠 봅니다. 라운드마다 순위가 따로 매겨집니다.
- **평균 점수**는 채점한 심사위원들의 평균, **심사 수**는 채점한 심사위원 수입니다.
- 동점이면 같은 순위를 공유하고 다음 순위는 건너뜁니다(1위, 1위, 3위). 점수가 없는 팀은
  순위 없이 아래에 표시됩니다.
- 진행 중인 대회는 **5초마다 자동 갱신**됩니다. 다른 탭을 보는 동안에는 갱신을 멈추고,
  돌아오면 즉시 최신 상태를 불러옵니다.
- 결선 순위는 시상식 전까지 운영자·심사위원에게만 보입니다.

### 팀빌딩

혼자 참가한 사람이 팀을 찾을 수 있게 돕습니다.

- **프로필** — 자기소개를 자유롭게 쓰면 기술 스택·관심 분야·역할 태그가 **자동으로 정리**됩니다.
  정리된 결과는 직접 고칠 수 있고, GitHub 주소도 함께 남길 수 있습니다.
  역할은 프론트엔드·백엔드·모바일·디자인·데이터·기획·AI 중에서 고릅니다.
  기술 스택은 **정해진 목록에서 여러 개 고릅니다**(검색·스크롤). 직접 타이핑하지 않는 이유는
  `react` / `리액트` / `React.js` 를 따로 세면 추천이 어긋나기 때문입니다. 목록에 없는 스택이
  자기소개에서 나오면 버리지 않고 그대로 보관하며, 운영자가 목록에 추가하면 자동으로 잡힙니다.
- **나에게 맞는 팀** — 팀에 없는 역할을 채울 수 있는지, 관심사가 겹치는지, 자리가 남았는지를
  따져 순위와 이유를 함께 보여줍니다.
- **팀에 맞는 사람** — 팀원과 운영자는 아직 팀이 없는 참가자를 같은 방식으로 추천받습니다.

추천은 제안까지입니다. 자동으로 배정하지 않고, 참가는 본인이 직접 누릅니다.

### 발표 진행

- 제출 시각순으로 발표 순서를 한 번에 배정한 뒤, 운영자가 ↑↓로 자유롭게 바꿉니다.
- 팀마다 발표 시간을 1~30분에서 따로 정할 수 있습니다.
- 타이머는 운영자가 **발표 시작**을 눌러야 돕니다. 팀 교체·쉬는 시간에는 멈춰 있어 앞 팀이
  늦어져도 뒤 팀 시간이 깎이지 않습니다.

### 시상

등수별 상 이름을 미리 등록해 두고, 시상식에서 최종 순위와 맞춰 순서대로 공개합니다.

## 역할별 사용 방법

### 운영자

1. 목록 화면 우측 상단 **+ 새 대회 만들기** — 대회명, URL 식별자(영문 소문자·숫자·하이픈,
   만든 뒤 변경 불가), 시작·종료 일시, 설명을 입력합니다.
2. 대회 상세 화면 상단의 단계 버튼으로 진행 상태를 바꿉니다.
3. **심사위원 배정**에 아이디를 입력하면 배정되고, **해제**로 뺍니다. 심사위원은 먼저
   회원가입해 두어야 합니다.
4. 대회 당일에는 스코어보드를 프로젝터에 띄워 두면 채점이 들어올 때마다 순위가 바뀝니다.
5. 테스트로 만든 대회는 상세 화면 맨 아래 **위험 구역**에서 삭제합니다. 딸린 데이터가 모두
   함께 지워지므로 대회 이름을 정확히 입력해야 실행됩니다.

### 참가자

1. **회원가입** 탭에서 아이디와 비밀번호(8자 이상)로 가입하면 바로 로그인됩니다.
2. 대회에 들어가 **내 팀빌딩 프로필**을 채웁니다. 자기소개만 써도 태그는 자동으로 정리됩니다.
3. **나에게 맞는 팀**에서 추천받아 참가하거나, **팀 만들기**로 새 팀을 엽니다.
4. 내 팀 카드에서 제출물 **제목·설명·링크**를 등록합니다. 진행중 단계까지 몇 번이든 고칠 수
   있고, 심사가 시작되면 잠깁니다.

### 심사위원

1. 배정된 대회에 들어가면 **심사하기** 영역이 나타납니다.
2. 팀별로 **예선**과 **결선** 점수(0~100, 0.5 단위)와 코멘트를 입력하고 저장합니다.
   제출물 링크는 **링크 열기**로 바로 확인할 수 있습니다.
   심사 도구를 열면 **저장소 사전 분석**이 먼저 보입니다 — 제출 저장소를 미리 읽어 "실제로
   구현된 것 / 껍데기만 있는 것 / 참고할 사실"을 근거 파일 경로와 함께 정리해 둔 것입니다.
   **점수는 제안하지 않습니다.** 분석이 점수를 띄우면 결국 모델이 채점하는 것과 같아지기
   때문에, 무엇이 있는지까지만 보여주고 판단은 심사위원이 합니다. 경로를 눌러 코드를 직접
   확인하세요. 운영자가 심사 전에 실행해 두며, 분석이 없어도 심사는 그대로 진행됩니다.
   저장소 코드 옆에는 **첫 커밋 시각과 커밋 수**도 표시됩니다. 대회 시작보다 이르면 그 사실을
   알려주지만 부정행위라고 판정하지는 않습니다 — 포크·저장소 이관 등 정당한 이유로도 앞설 수
   있어, 확인은 심사위원이 직접 합니다.
3. 저장한 점수는 다시 열어도 그대로 있고 **점수 수정**으로 언제든 고칠 수 있습니다.
4. 채점은 대회가 **심사중** 단계일 때만 저장됩니다.

## 자주 묻는 질문

**운영자 권한은 어떻게 받나요?**
관리자가 해당 계정에 스태프 권한을 켜 주면 됩니다. 로그인하면 이름 옆에 `운영자` 표시가 붙고
대회 생성·단계 전환·심사위원 배정 메뉴가 나타납니다.

**팀 만들기 버튼이 안 보여요.**
대회가 모집중 단계가 아닙니다. 팀 구성은 모집중일 때만 가능합니다. 운영자에게 요청하면 모집중
단계로 되돌릴 수 있습니다.

**제출물 수정 버튼이 사라졌어요.**
대회가 심사중 또는 종료 단계입니다. 제출물은 모집중·진행중 단계에서만 바꿀 수 있습니다.

**점수 저장이 안 돼요.**
대회가 심사중 단계인지 확인하세요. 배정되지 않은 대회에서는 심사하기 영역 자체가 보이지 않습니다.

**프로필 자동 정리가 안 돼요.**
자동 정리는 선택 기능입니다. 실패하거나 버튼이 없어도 태그를 직접 입력하면 추천은 똑같이
동작합니다.

**로그인이 풀렸다는 안내가 떠요.**
로그인 유지 기간이 지났습니다. 다시 로그인하면 이전 작업 내용은 모두 남아 있습니다.

**첫 접속이 느려요.**
서버가 한동안 쓰이지 않으면 잠들었다가 깨어나느라 수십 초가 걸립니다. "서버를 깨우는 중입니다"와
경과 시간이 표시되니 기다리면 됩니다. 한 번 깨어나면 이후는 빠릅니다. 대회 당일에는 참가자
가입과 팀 구성을 미리 끝내 두는 것을 권합니다.

**비밀번호를 잊었어요.**
셀프 재설정 기능은 아직 없습니다. 운영자에게 요청하면 새 비밀번호를 설정해 줍니다.

**대회가 끝나도 기록이 남나요?**
남습니다. 대회·팀·제출물·점수·시상 기록은 지우기 전까지 그대로 보관되고, 종료된 대회의
스코어보드도 계속 열람할 수 있습니다. 데이터베이스는 매주 자동으로 백업됩니다.
대회 삭제만은 되돌릴 수 없으니, 위험 구역에서 대회 이름을 정확히 입력해야 실행됩니다.
