# HACKMAN 모바일 앱 UI 시안

Claude Artifact(Design canvas)로 그린 모바일 UI 목업. 원본: https://claude.ai/artifact/YQKha2gYH7m5BSE1dAW8vx

- `Auth.dc.html` — 로그인
- `Main.dc.html` — 홈
- `ContestDetail.dc.html` — 대회 상세
- `Submission.dc.html` — 제출물 심사
- `Gallery.dc.html` — 프로젝트 갤러리
- `Profile.dc.html` — 프로필

`canvas.json`은 캔버스 레이아웃(아트보드 배치) 정보. `.dc.html` 파일은 Claude Design Component 포맷이라
`<script src="./support.js">`에 의존하며 브라우저에서 단독으로는 렌더링되지 않음 — 참고/보관용 스냅샷.
