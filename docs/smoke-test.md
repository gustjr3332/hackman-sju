# 배포 후 스모크 테스트

배포마다 반복. 위에서부터 순서대로, 안 되면 그 자리에서 멈추고 원인부터 확인한다.
소요 시간: 전부 통과하면 10분, 로그인 문제 나오면 +10분.

## 0. 배포 확인 (1분)

- [ ] `npx supabase functions deploy` 실행함 (백엔드 바뀐 게 있으면)
- [ ] `main` 브랜치 push 됨 → Vercel 배포 완료(대시보드에서 초록불 확인)
- [ ] `https://hackman-sju.vercel.app` 접속되고 빈 화면·흰 화면 아님

## 1. 비로그인 (3분)

- [ ] 첫 화면이 **대회 목록**이다 (로그인 폼이 기본으로 안 보임)
- [ ] 우측 상단 **"로그인" 버튼**이 있고, 누르면 로그인 폼이 펼쳐진다
- [ ] 로그인 폼 안 누른 상태로 대회 하나 클릭 → 상세 화면 들어가짐
- [ ] 상세 화면에서 "제출물 둘러보기" → 갤러리 진입, 팀 카드·예선 점수 보임
- [ ] 갤러리에서 팀 하나 클릭 → 프로젝트 상세(소개·데모·GitHub) 보임
- [ ] 종료된 대회에서 **결선 탭이 안 보인다** (비로그인은 예선만)
- [ ] 페이지 맨 아래에 기술 스택 문구("Supabase + React" 등) **없음**
- [ ] 브라우저 콘솔(F12) 에러 없음

## 2. 로그인 (5분) — 비밀번호는 직접 입력, AI에게 안 시킴

- [ ] **아이디로 로그인** (`admin` 등, 이메일 안 씀) 성공
- [ ] **이메일로 로그인**도 여전히 성공
- [ ] **틀린 비밀번호**로 시도 → "아이디(이메일) 또는 비밀번호가 맞지 않습니다" 뜸
- [ ] **존재하지 않는 아이디**로 시도 → 위와 **똑같은 문구** (계정 있는지 없는지 티 안 남)
- [ ] 로그인 후 헤더에 이름·역할(운영자/참가자) 표시됨
- [ ] 로그아웃 → 다시 로그인 폼 기본 숨김 상태로 돌아감

## 3. 역할별 기능 (역할마다 5분)

| 역할 | 확인할 것 |
|---|---|
| 참가자 | 팀 생성/참가, 제출물 등록, 본인 점수만 보임 |
| 심사위원 | 배정된 대회만 채점 화면 보임, 점수 저장 반영 |
| 운영자(admin) | 대회 생성/수정, 심사위원 배정, 시상 등록, 결선 점수·심사 보조 분석 조회 |

각 역할 로그인 → 표에서 본인 줄만 확인하면 됨 (전부 한 사람이 할 필요 없음).

## 4. 실패 시

- 콘솔 에러 스크린샷 + 어느 단계에서 멈췄는지 적어서 공유
- 로그인 관련이면 `supabase functions deploy login` 다시 됐는지부터 확인 (배포 안 되고 옛날 함수가 떠 있는 경우가 제일 흔함)
